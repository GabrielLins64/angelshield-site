# Privacidade do AngelShield

Página pública da política de privacidade do AngelShield.

- Política: https://gabriellins64.github.io/angelshield-privacy/
- Suporte: https://github.com/GabrielLins64/angelshield-privacy/issues

## Publicação

O GitHub Pages publica o arquivo `index.html` a partir da raiz da branch `main`. O arquivo `.nojekyll` indica que o conteúdo é HTML estático, sem etapa de build própria.

Para atualizar a política, edite `index.html`, revise a data da atualização e envie um commit para `main`. A versão de referência também fica em `docs/privacy.html` no projeto AngelShield; mantenha os dois arquivos alinhados.
